## Lessons

- localStorage mirror + long heartbeat stale window ≈ “stay logged in after browser close”
- Do not `clearAllAuthStorage` on stale heartbeat alone when `tab_count > 0` without probing — kills sleeping peer via `syncAuthMirrorToSession`
- Chrome pinned + “continue where you left off” restores sessionStorage; treating restored tokens as live was the bug. In-memory confirm flag + no cross-pong between restored tabs.
- Always import symbols used after cache-refactors; Promise.all(getTasks, getUsers) surfaces getUsers ReferenceError as “Failed to load delegation tasks”
- Bot lockout: strike on bot-check fail (not wrong password); clear strikes on successful human login
- Select value UUID without matching option label = Ant Design shows raw id; never `Promise.all` unrelated loads for one toast
- Machine callers need a separate key-auth path; do not weaken SPA bot-protect — exempt only `/integrations/`
- `logging.getLogger()` is not callable — use `.info` / `.exception`
- PowerShell `Set-Content` can corrupt `.env` encoding; rewrite with Python UTF-8
